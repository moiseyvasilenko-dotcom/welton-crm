# Welton CRM — Telegram Mini App MVP

Минимальная CRM без сервера: клиенты, сделки и задачи хранятся в `localStorage` устройства.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Подключение к Telegram

После получения токена:
1. Разместить приложение на HTTPS.
2. Создать кнопку Mini App через BotFather или код бота.
3. Указать публичный HTTPS URL.
4. На следующем этапе заменить локальное хранилище на серверное, если CRM должна быть общей для нескольких сотрудников.
